# database/baseline

`000_rebuild.sql` — the live schema as one guarded, dependency-ordered SQL
file; what a blank Supabase project runs to become this one. GENERATED by
`npm run build:baseline` over `public.schema_dump()` (migration 227); never
edited by hand. `database/MIGRATIONS.md` → "To build an environment" is the
runbook. The file is absent until 227 has run on the source and the
generator has been run once.
