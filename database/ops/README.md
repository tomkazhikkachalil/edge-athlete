# One-off operations — run by hand, once, recorded in DEVLOG

Not migrations: no DDL, not in the chain, not in the ledger. Each file here is
a data operation that ran ONCE on a named environment on a named date, with
the record in `DEVLOG.md`. Re-running one is never routine — read its header.

- `2026-09-30-prod-reset.sql` — the production reset before the public
  launch: every user-data table truncated (118), the catalogs kept
  (`scripts/prod-reset/tables.mjs` is the classification, pinned by
  `src/lib/__tests__/prod-reset-tables.test.ts`). Generated by
  `scripts/prod-reset/generate-sql.mjs`; the snapshot came from
  `scripts/prod-reset/export.mjs` and storage + auth were emptied by
  `scripts/prod-reset/wipe.mjs`.

`snapshots/` is gitignored: it holds the exported rows and files (PII) on the
operator's machine only.
